# 明信片柜

一个手机端明信片收藏 App 原型，当前版本是纯前端静态应用。

## 运行

直接用浏览器打开 `index.html` 即可。

## iPhone 测试

项目已配置为 PWA，并通过 GitHub Pages 部署。部署完成后，用 iPhone Safari 打开 Pages 地址，点分享按钮，再选择“添加到主屏幕”。

## 已实现

- 明信片柜首页
- PWA manifest、离线缓存和主屏幕图标
- 开放式分层展示架，不显示层号，也不和词条绑定
- 筛选结果按顺序从上到下摆放，超出一架后分页
- 现有词条点击过滤，时间可按新到旧或旧到新排序
- CSS 绘制文艺复古架子，不依赖图片素材
- 极简扫描入柜
- 正面/背面拍照或上传
- 拍照后手动四角裁切，透视拉正并做轻量扫描增强
- 时间、词条标签和备注
- 保存入柜并写入浏览器 `localStorage`
- 架子内明信片正反面翻看
- 全屏查看明信片，支持点击翻转、拖动平移、滚轮/双指缩放和物理卡厚度
